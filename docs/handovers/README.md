# Session handovers (local-only)

This directory holds the dated session-handover files
(`prismaquant-handover-YYYY-MM-DD*.md`), moved here from `.claude/` so all
documentation lives under `docs/`. They are **gitignored** — session history is
local working state, not published documentation. A fresh clone of this repo
will not contain them.

Read them for narrative arc only. Their "open items / next steps" sections are
point-in-time and frequently superseded — check `docs/ARCHITECTURE.md`, the
auto-memory index, and the code before acting on anything listed in one. A
census with per-handover staleness verdicts (2026-07-30) lives in the local
`scratch/doc-consolidation-2026-07-30/census_handovers.md`.

Multi-model deliberation records (Codex/Gemini briefs and transcripts) remain
in `.claude/codex-*` and `scratch/deliberation/`, also local-only; see
`docs/README.md` for the index.
